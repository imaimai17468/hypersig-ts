API reference

Set up the Hono adapter and declare how Actions and Live Views use server data.

Hono adapter

createHypersig(options)
Set the public origin, session authentication, and Pub/Sub implementation.
hypersig.routes
Mount the Action and SSE endpoints on the Hono application after registering Actions.
hypersig.page(request, render)
Authenticate the request and render the page as HTML.

Actions

Use hypersig.action(name, definition) with Standard Schema input and output definitions, an authorize check, and an execute function. 

<button type="button" {...increment.bind({ counterId: "main" })}>
  Increment main
</button>

action.bind(input) binds typed data to a button. action.form() supplies attributes for an HTML form. The Action response reports the result. Subscribed Views update over SSE.

Live Views

key
Returns a stable identifier within the current boundary.
subscribe
Returns the Topics that affect this view.
authorize
Checks that the session can see this view.
load
Reads the data to display.
render
Converts the data to HTML.

Use page.view(view, props) to place the boundary in the document.

Topics

const changed = topic("counter", (id: string) => id);
await hypersig.publish(changed(id));

Publish after the state change commits. The Topic identifies the changed data. Each View defines its own subscriptions.
