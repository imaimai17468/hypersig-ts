Get started

Run the Counter example locally and check that two tabs show the same committed value.

Set up the repository

Install mise to use the Bun and Node versions pinned in the repository. 

git clone https://github.com/imaimai17468/hypersig-ts.git
cd hypersig-ts
mise install
mise exec -- bun install --frozen-lockfile
mise exec -- bun run example:counter

Try two tabs

  1. Open http://127.0.0.1:3000 in two tabs.
  2. Select Increment main in one tab.
  3. Check that the shared counter updates in both tabs and the independent counter keeps its value.

The examples keep their state in memory. Restarting the server resets it. Open the other tab in a private window to test separate sessions.

Read the example

The Counter source contains the HTTP routes, the Action, and the Live View. For a larger example, run mise exec -- bun run example:todomvc.

  1. increment validates input and changes the value, then announces it with hypersig.publish(counterChanged(counterId)).
  2. counter defines the part of the page that updates. Its subscribe names the same change, and its load reads the value.
  3. page.view(counter, { id: "main" }) renders that view in the page and registers it to receive updates.

With your own data, start with one read and one write. Subscribe the view to the change you publish after the write. Check permissions in both the write operation and the view.
