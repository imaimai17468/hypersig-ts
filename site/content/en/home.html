Data changes are committed on the server. You specify which changes to announce and which parts of the page subscribe. The browser applies the HTML rendered from the committed data.

Where displayed values are decided

If an application keeps separate copies of its order list and totals in the browser, saving an order also means deciding how to refresh each copy. hypersig.ts renders those views from the saved data and sends them to their subscribers. The same process applies to a change made by the current user, another user, or a scheduled job.
