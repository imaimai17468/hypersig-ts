A TypeScript framework

Server updates
across open tabs

Data changes are committed on the server. When another user saves or a background job changes the data, the server sends updated HTML to the parts of the open pages that display it.

How pages update

Commit changes on the server

Validate input and check access. Send a notification after the change is saved.

Send HTML for the affected regions

Define which data each region displays. When that data changes, render the region on the server again.

Keep unfinished input in the browser

The server renders the components. The browser applies the HTML while preserving focus and unfinished input where possible.
