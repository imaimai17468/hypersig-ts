Live HTML from server state

hypersig.ts is a TypeScript web framework that updates parts of a page from committed server state. When data changes, it sends HTML for the affected views to open pages.

Keep pages in sync

A view shows data as it was when the server read it. The server sends changes as they happen and reads the current state on reconnect.
