with the server

サーバーで変更が確定すると、画面の必要な箇所が更新されます。保存後の表示更新や再接続時の同期を、画面ごとに実装する手間を減らします。

サンプルを動かす 設計の背景を読む

表示はいつでも古くなりうる

画面に届くのは、サーバーが読み取った時点のデータです。表示した直後でも、その間に保存が確定していれば、表示はもう古くなっています。

変更が画面に届くまで

  1. サーバーで変更を確定する

    サーバーで入力を検証し、データを保存します。保存が確定したら、何が変わったかをアプリのコードで明示的に通知します。

  2. 関係する箇所だけを更新する

    開発者は、画面の各部分がどの変更を受け取るかを指定します。サーバーは指定に従って HTML を生成し、ブラウザは該当箇所に反映します。

  3. 接続が戻ったら同期する

    ブラウザは古い更新を適用せず、再接続時にはサーバーの最新状態から生成した HTML を受け取ります。
