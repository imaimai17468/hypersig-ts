デプロイ

HTML を生成し、POST を処理し、SSE 接続を維持できるサーバーでアプリを実行します。

ブラウザランタイムの配信

mise exec -- bun run build で dist/runtime.js を生成します。アプリと同じオリジンで配信し、page.runtime("/runtime.js") で読み込みます。

このサイトは静的なドキュメントです。ライブ更新を試す際は、アプリケーションサーバーでサンプルを起動してください。

アクセス権の設定

公開オリジンを設定し、認証処理から安定したセッション識別子を返します。Action と Live View のそれぞれでアクセス権を確認します。永続化する状態はアプリケーションのデータベースに保存します。

ライブ接続のルーティング

ページ登録は、ページを生成したサーバーインスタンスに保存されます。複数インスタンスでは、対応する SSE リクエストをそのインスタンスに送ります。インスタンスをまたぐ変更には、対象 View の配信を担当するサーバーへ通知できる Pub/Sub アダプターを使います。

プロキシが SSE をバッファリングせず、長時間の接続を維持できることを確認します。
