API リファレンス

Hono に組み込み、サーバーで入力を処理して画面の一部を更新します。

Hono への組み込み

createHypersig(options)
アプリの公開 URL のオリジン、ログイン状態を確認する関数、変更通知を購読先に配る仕組みを指定します。
hypersig.routes
操作を受け付ける URL と更新を配信する URL を、Hono のルートに追加します。サーバーで実行する処理を登録してから追加します。
hypersig.page(request, render)
リクエストを認証し、ページの HTML を生成します。

フォームやボタンからの操作

フォーム送信などで実行するサーバー上の処理を Action と呼びます。

hypersig.action(name, definition) で登録します。Standard Schema に対応するスキーマで入力と出力を検証し、authorize で操作する権限を確認してから execute を実行します。 

<button type="button" {...increment.bind({ counterId: "main" })}>
  Increment main
</button>

action.bind(input) は送信する値をボタンに設定します。action.form() はフォームに渡す属性を返します。サーバーは処理結果を応答として返します。

データ変更の通知

通知の対象を表す名前とキーの組み合わせを Topic と呼びます。たとえば、カウンターという名前と、どのカウンターかを表す ID を組み合わせます。 

const changed = topic("counter", (id: string) => id);
await hypersig.publish(changed(id));

データを保存したあとで、hypersig.publish を使って変更を通知します。

変更に合わせて更新する画面の一部

関連するデータが変わったときに更新する画面の一部を Live View と呼びます。page.view(view, props) でページ内に配置します。

key
ページ内の同じ表示を識別できる、変わらない値を返します。
subscribe
受け取る変更通知の対象を Topic で指定します。
authorize
現在のセッションで表示できるかを確認します。
load
表示するデータを取得します。
render
データから該当部分の HTML を生成します。

サーバーは、購読しているデータに変更があると、更新後の HTML をブラウザに送信します。
