API リファレンス

Hono アダプターを組み込み、Action と Live View が使うサーバーデータを定義します。

Hono アダプター

createHypersig(options)
公開オリジン、セッション認証、Pub/Sub の実装を指定します。
hypersig.routes
Action を登録したあとで、Action と SSE のエンドポイントを Hono にマウントします。
hypersig.page(request, render)
リクエストを認証し、ページの HTML を生成します。

Action

hypersig.action(name, definition) に Standard Schema の入出力、authorize の認可処理、execute の実行処理を渡します。 

<button type="button" {...increment.bind({ counterId: "main" })}>
  Increment main
</button>

action.bind(input) は型付き入力をボタンに紐づけます。action.form() は HTML フォームの属性を返します。Action の応答は処理結果を通知し、購読中の View は SSE で更新します。

Live View

key
境界内で安定した識別子を返します。
subscribe
表示に影響する Topic を返します。
authorize
現在のセッションで表示できるかを確認します。
load
表示するデータを取得します。
render
データから HTML を生成します。

page.view(view, props) でドキュメントに更新境界を配置します。

Topic

const changed = topic("counter", (id: string) => id);
await hypersig.publish(changed(id));

状態変更を確定したあとで発行します。Topic は変更されたデータを識別します。各 View が購読先を定義します。
