はじめる

カウンターのサンプルを手元で起動します。片方のタブで値を変え、もう片方にも反映されることを確認します。

リポジトリのセットアップ

mise をインストールし、リポジトリが指定する Bun と Node を使います。 

git clone https://github.com/imaimai17468/hypersig-ts.git
cd hypersig-ts
mise install
mise exec -- bun install --frozen-lockfile
mise exec -- bun run example:counter

二つのタブで確認する

  1. http://127.0.0.1:3000 を2つのタブで開きます。
  2. 片方で Increment main を押します。
  3. 両方の共有カウンターが更新され、独立カウンターの値がそのまま残ることを確認します。

サンプルの状態はメモリにあり、サーバーの再起動でリセットされます。別セッションで試す場合は片方をプライベートウィンドウで開きます。

実装を読む

Counter のソースで、サーバーで値を変更する処理と、その値を画面に表示するコードを確認できます。項目の追加や絞り込みを試す場合は mise exec -- bun run example:todomvc を実行します。
